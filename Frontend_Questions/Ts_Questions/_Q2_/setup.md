## setup Typescript


```sh 

npm init -y 

npm i --save-dev typescript 

npx tsc --init

``` 

- uncomment the root and outer dir 

- script script to run code 

```json 
 "scripts": {
    "code" : "node ./dist/code.js",
    "build" : "npx tsc --watch" 
  },

```
