### Teen concepts ka aapas mein connection
```md 

**Execution context** → har function call pe banta hai; usme lexical environment hota hai.

**Lexical environment** → variables/functions store hote hain; yahi se scope chain banti hai.

**Hoisting + TDZ** → creation phase mein kaise variables register hote hain aur kab access allowed hote hain.

**Closure** → jab inner function outer lexical environment ko reference karta hai, toh wo environment zinda rehta hai, bhale outer context stack se hat chuka ho.

```
