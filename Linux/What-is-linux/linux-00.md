# What is linux ? 
**Linux** is commonly used to refer to an operating-system environment built around the **Linux kernel**, together with system utilities, libraries, package managers, shells, and other software. **Linux Kernel** is the core component of an operating system that directly manages the computer's hardware and provides essential services to software applications.

-  Technically, "Linux" is just the kernel—the central program that talks directly to computer hardware like the CPU, memory, and storage. It handles tasks like memory allocation, file writing, and device drivers so apps do not need to know the physical details of the machine


## What is a Distribution (Distro)?
  * Complete system: Because the kernel is free, developers bundle it with system libraries, utilities, and a  desktop interface (GUI) to create a ready-to-use operating system called a distribution or distro.
  * Popular versions: Well-known distros include Ubuntu, Fedora Linux, Linux Mint, and Debian.
  * Other uses: Android phones and smart TVs also use the Linux kernel, though they are not traditional desktop distributions
